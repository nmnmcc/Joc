# Security Policy

## Supported versions

Joc is an early-stage project. Security fixes are applied to the `main`
branch; released versions are not currently maintained separately.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Send a
private report to [huangyinhaow@outlook.com](mailto:huangyinhaow@outlook.com)
with the affected commit or version, the steps to reproduce the issue, and
any relevant logs that do not contain personal data.

You can expect an acknowledgement within seven days. Please allow time for
the issue to be investigated and fixed before sharing details publicly.
